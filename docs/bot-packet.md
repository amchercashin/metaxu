# Пакет для Grok Bot

> **Архив, не выполнять как действующий план.** Инструкции ниже про Godot,
> обязательный день у реки и распределение задач ботам устарели.
> Читать [WINDOWS-HANDOFF.md](WINDOWS-HANDOFF.md) и корневой AGENTS.md.

Отдай ботам в таком порядке. Не отдавай всё сразу одному боту.

## Общий закон

Читать сначала `DESIGN.md`.  
Не добавлять уровни, skill tree, открытый мир, LLM-диалоги.  
Голоса героев только авторские.  
Первый результат — один день у реки, а не игра целиком.

## Задачи по ролям

### Producer
- Держать scope v0: речной день.
- Вести список флагов памяти.
- Резать любые предложения вне круга 12–13.

### Systems (Godot 4)
- Два актёра: Kleón, Ariston.
- Состояния тела, имя, свиток, долги, спор дня.
- Режиссёр: из пула 8 карточек выбрать 3 по тегам и памяти.
- Сохранение дня.
- Данные событий читать из `events/river_day.md`.

### World
- Один ленточный участок: склон из валунов, пальмы, река, туман, два берега, камыш, возможный брод.
- День начинается на склоне, кончается лагерем на одном из берегов.
- Природа читаема: течение видно, следы видны, туман врёт про дистанцию.

### Writer
- Не переписывать канон голоса.
- Дописать диалоги внутри карточек `events/river_day.md` там, где стоят пометы AUTHOR.
- Старший не оракул.

### Action
- Ходьба, камера, вход в воду, потерять/удержать ношу, короткий контакт со зверем.
- Глаголы из круга 11.

### QA
Три запуска. Записать:
1. какие 3 события выпали;
2. цена каждого запуска;
3. жив ли страх;
4. не стал ли Старший учителем уровня;
5. хочется ли четвёртый запуск.

## Критерий приёмки

Три разных запуска одного дня = три связные истории той же игры.  
После этого можно добавить 2 новые карточки в тот же пул, не трогая движок.
