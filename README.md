# Metaxu

**μεταξύ** — «между».

Metaxu — браузерная 3D-RPG о путешествии двоих героев в эпоху Демокрита. Игрок исследует скрытую туманом карту, встречает людей, говорит, дерётся и живёт с последствиями. Философия здесь проверяется действием, а не выносится в отдельные лекции.

Играть: https://amchercashin.github.io/metaxu/

## Текущий промежуточный билд

Сейчас готов один небольшой регион — окрестности Абдеры около 430 года до н. э. В нём есть:

- двое героев и смена ведущего;
- пешее исследование и карта из 37 ячеек с туманом войны;
- Абдера, гавань, высота, брод, восточная дорога и разорённое святилище;
- авторская дорожная встреча: наблюдение, диалог, отход или бой;
- короткий нелетальный бой с дистанцией, выносливостью и самообладанием;
- последствия победы, поражения и отступления; поражение не заканчивает игру;
- сохранение пути в браузере.

Это ещё системный прототип. Процедурные модели, анимации, звук и окружение временные; текущая картинка не является заявленным финальным качеством. Река осталась в репозитории как возможная локация, но больше не является ядром игры.

## Управление

- `WASD` — идти;
- `Shift` — бежать;
- мышь — камера;
- `C` или `Tab` — сменить ведущего;
- `E` — взаимодействовать;
- `M` — открыть карту.

## Локальный запуск

Нужны Node.js 22 и pnpm.

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm dev
```

Проверка production-сборки:

```bash
pnpm build
pnpm preview
```

## Стек и структура

- TypeScript + Vite;
- Babylon.js 9: WebGPU с запасным WebGL2;
- Havok WASM для физики;
- HTML/CSS-интерфейс поверх 3D-сцены;
- IndexedDB для локального сохранения.

`src/sim/` содержит чистые сериализуемые системы; `src/content/` — авторские встречи; `src/view/` — 3D-мир, камеру и персонажей; `src/ui/` — карту, диалоги, бой и сохранение.

Актуальная рамка дизайна: [docs/DESIGN.md](docs/DESIGN.md).
