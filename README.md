# Metaxu

**μεταξύ** — «между».

Путь в игре — «Двое на восток»: Клеон и Аристон идут по слуху о путешествии Демокрита, до Александра. Это не имя продукта.

Срез v0: один день у реки. Режиссёр выбирает 3 из 8 авторских событий. Утро и вечер фиксированы. Мир помнит, кто нёс тяжесть. Свиток — вещь в руках.

Страница: https://amchercashin.github.io/metaxu/

## Запуск

Нужны Node 22. Скрипты в package.json: test, dev, build. Vite base: /metaxu/.

## Стек

- TypeScript, Vite
- Babylon.js (@babylonjs/core 9.x, не Lite): WebGPU, запасной путь WebGL2
- Havok для тел; если WASM не поднялся — кинематика + сила течения
- Вода: объём и ток, без симуляции жидкости
- Диалоги: авторский русский текст; тонкий ink-подобный граф
- UI: HTML/CSS поверх холста, без React
- Сохранение: IndexedDB (в тестах — адаптер в памяти)

## sim и view

src/sim/ — день, тела, имена, свиток, долги, спор дня, флаги, режиссёр, снимок. Без импортов Babylon.

src/content/ — JSON карточек событий и схема.

src/view/ — сцена, камера, ввод, Havok, лента мира.

src/ui/ — выборы, речь, вечерний пересказ, кнопка сохранения.

## Как играть

1. Утро на валунах: три реплики задают argument_of_day (node | distinction | haste).
2. Клавиши ходьбы вдоль ленты (восток — вперёд). C или Tab — сменить ведущего; спутник идёт следом.
3. Река несёт течением. В воде можно отпустить свиток.
4. Тёплый круг — событие. Три за день.
5. Вечер на берегу или без огня. Спор дня не закрывается.
6. Кнопка «Сохранить» пишет день в браузер.

Разные зёрна дают разные тройки событий.

## Чем v0 не является

Нет уровней, древа навыков, открытого мира, моральной шкалы, инвентаря, крафта, карты континента.
