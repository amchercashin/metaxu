# Metaxu

Концепция, художественные ориентиры, стек и состояние проекта:
[docs/WINDOWS-HANDOFF.md](docs/WINDOWS-HANDOFF.md).

На Windows начинается новая реализация на Unity + URP + Blender.
Старый Babylon-прототип в корне — справочный архив, не основа для обязательного порта.
Новый Unity-проект — unity/Metaxu/.

Ранний Godot-план и обязательный «день у реки» отменены.
docs/bot-packet.md — архивный материал.

Локальное Windows-окружение и проверенные команды:
[docs/WINDOWS-ENVIRONMENT.md](docs/WINDOWS-ENVIRONMENT.md).
Первичная настройка завершена: Blender, Play Mode, Windows exe и оба MCP проверены.
Тестовая сцена не определяет игровые механики или художественный стиль.

Художественное правило пользователя: узнаваемая историческая Абдера, одежда,
архитектура и быт; домысливать при недостатке свидетельств, обозначая допущения.
Природа красивая и слегка сказочная, фотореализм не обязателен. Актуальная основа:
[docs/art/abdera-study-2026-09/HISTORICAL-BASIS.md](docs/art/abdera-study-2026-09/HISTORICAL-BASIS.md).
